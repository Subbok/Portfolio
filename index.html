LLM Benchmark Pipeline — Praca Magisterska

GitHub →

Pipeline do porównania 10 dużych modeli językowych (LLM) na zadaniach tekstowych i kodowych — automatyczne zbieranie odpowiedzi, ewaluacja wieloma metrykami i analiza wyników.

▸Zunifikowany collector: Ollama (lokalne) + OpenRouter API (komercyjne)
▸4 metryki: Pass@1, CodeBLEU (AST + dataflow), BERTScore (RoBERTa-large), G-Eval 1-100
▸Master pipeline (Bash) z zarządzaniem środowiskiem conda i detekcją VRAM
▸10 modeli (Claude, GPT, Gemini, Grok, DeepSeek, KIMI + Qwen, Llama, Mistral, Gemma)
▸Sandboxowane wykonywanie kodu z timeout protection — 184 testy jednostkowe
▸GPU-accelerated ewaluacja (CUDA/PyTorch) z automatycznym fallbackiem na CPU
